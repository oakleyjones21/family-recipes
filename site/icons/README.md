# Icons & logo

Line icons for the recipe site and Notion: a 24px grid, a 1.5px stroke and rounded ends.

- `svg/`: for the website. The stroke is `currentColor`, so an icon pasted into the HTML takes on the color of the text around it.
- `png/`: for Notion page icons. 280×280, transparent, brown `#4A3A2A`.
- `../logo/`: the logo marks, as SVG and as 512px PNG.

In Notion, click a page's icon, choose **Link** and paste a PNG address from the table.
